## Prime and Spines Configuration

This project extends the Prime Byzantine Fault-Tolerant Replication system and its accompanying Spines networking infrastructure through the development of configuration automation, deployment utilities, and testing tools.

The objective is to streamline the configuration and deployment of Prime across multiple environments, including Docker-based and physical machine deployments, while supporting performance evaluation and experimentation.
